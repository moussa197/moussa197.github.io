## Structure du site

| Fichier | Rôle |
| ------- | ---- |
| `index.html` | Contenu de la page |
| `style.css`, `enhancements.css` | Mise en page, thèmes clair et sombre, responsive |
| `script.js` | Thème, filtres de projets, copie de l'adresse e-mail |
| `glyph-field.js` | Champ de caractères de code qui s'illumine autour du curseur, dans l'en-tête |
| `chat-widget.js`, `chat-widget.css` | Interface de l'assistant Ask Moussa, relié à l'API hébergée sur Render |
| `cv/cv-moussa-keita.pdf` | CV ouvert par le lien « Voir mon CV » |

Le site n'a aucune dépendance : il suffit d'ouvrir `index.html` dans un navigateur.
Pour mettre le CV à jour, remplacez `cv/cv-moussa-keita.pdf` en gardant le même nom.
